# Control Monotributo · Demo

Demo pública de la herramienta **Control de categorización del monotributo** de Analytik. Cruza facturación, acreditaciones bancarias y las escalas de ARCA para mostrar categoría, margen y semáforo. Todo se calcula en el navegador.

Página: https://analytikcoorp.github.io/control-monotributo/

Esta demo trabaja solo con datos de ejemplo. La versión completa (carga de facturación y extractos reales) vive en el repositorio privado `control-monotributo-full` y se entrega al cliente tras la compra.

`escalas.json` es compartido: lo mantiene una tarea programada que agrega las vigencias de febrero y agosto (ver `ACTUALIZAR_ESCALAS.md`). La versión completa lee el mismo archivo desde esta URL.
